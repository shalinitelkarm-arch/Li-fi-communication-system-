Project Description
LiFi (Light Fidelity) is a wireless communication technology that uses visible light to transmit data. The project demonstrates data transmission using a mobile flashlight as the transmitter and an LDR as the receiver.
Components Used
Arduino UNO
LDR (Light Dependent Resistor)
Mobile flashlight as transmitter
16×2 LCD display
Jumper wires
Breadboard
Working
The transmitter sends information using rapid changes in light intensity. The LDR detects these changes and sends the signal to Arduino UNO. Arduino processes the received signal and displays the decoded information on the LCD.
Applications
Wireless communication
Indoor communication
Smart lighting systems
Secure data transmission
